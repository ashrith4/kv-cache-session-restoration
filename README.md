# KV Cache and Session Restoration

## Overview
This project investigates the performance and efficiency of restoring KV (Key-Value) caches when AI agent sessions resume. The main objective is to understand the trade-offs between restoring stored KV caches, recomputing them, and using context compaction techniques.

## Research Questions
* **Q1:** Developing a cost model for exact KV cache restoration.
* **Q2:** Comparing exact restoration with context compaction techniques.
* **Q3:** Investigating the impact of background agent I/O on KV cache restoration.

## Project Goals
* Study existing research and identify research gaps.
* Develop experimental methods to evaluate KV cache restoration.
* Measure restoration performance under different conditions.
* Analyse results and validate performance predictions.
